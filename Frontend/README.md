# Guapi Verde — Frontend

Interface mobile-first do Guapi Verde, criada com React, JavaScript, Vite, Tailwind CSS e suporte básico a PWA.

## Como executar

1. Copie `.env.example` para `.env` se precisar alterar a URL da API.
2. Instale as dependências com `npm install`.
3. Inicie o ambiente de desenvolvimento com `npm run dev`.

Comandos disponíveis:

- `npm run dev`: inicia o servidor de desenvolvimento;
- `npm run lint`: verifica o código;
- `npm run build`: gera a versão de produção em `dist`;
- `npm run preview`: serve localmente a versão de produção.

Nesta etapa, a página inicial consome categorias, atrativos, imagens e eventos da API. As demais páginas continuam como estruturas visuais para integrações futuras.
